# ALCORTA — actualización de la carta

La carpeta conserva el repositorio Git original y está preparada para Netlify.

Desde esta misma carpeta:

```powershell
git status
git add -A
git commit -m "Nuevo diseño de la carta"
git push
```

Netlify publica automáticamente la carpeta `public` gracias al archivo `netlify.toml`.
